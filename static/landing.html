// Core Features

重新定义 AI 推理的边界

四大核心技术突破，让分布式推理从理论走向生产可用

智能模型分片

将大型模型按 Transformer 层自动分割成多个分片，每个节点只加载和执行部分层。 支持异构硬件混合部署——GPU、NPU、甚至消费级显卡均可参与。

隐藏状态高速传递

分片间仅传递紧凑的隐藏状态张量，而非庞大的 KV 缓存。 通过 gRPC 实现节点间低延迟通信，保证分片推理与完整模型推理完全等价。

独立 KV 缓存管理

每个节点独立管理自己负责层的 KV 缓存，采用 LRU 策略高效复用缓存资源。 ModelState 统一调度多请求并发，最大化内存利用率。

P2P 去中心化拓扑

基于 P2P 协议构建弹性网络拓扑，支持节点动态加入与退出。 内网穿透技术让 NAT 后设备也能无缝接入集群，无需公网 IP。

OpenAI 兼容 API

完全兼容 OpenAI API 格式，支持 /v1/chat/completions 和流式输出。 一行代码即可将现有应用迁移到 EXO 集群，零学习成本切换。

企业级安全体系

API Key 管理、JWT 身份认证、请求配额控制、操作审计日志一应俱全。 AES-256 加密通信，确保数据在传输和存储过程中的绝对安全。
