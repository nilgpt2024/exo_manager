Privacy Policy

最后更新：2024年1月1日

我们重视您的隐私

EXO 分布式推理平台（以下简称"我们"或"本平台"）深知个人信息对您的重要性，我们将按照法律法规要求，采取相应安全保护措施，尽力保护您的个人信息安全可控。

本隐私政策旨在向您说明我们如何收集、使用、存储、共享和保护您的个人信息。请您仔细阅读，如有疑问可通过文末联系方式与我们联系。

我们收集的信息

1.1 您主动提供的信息

信息类型 用途 是否必须
用户名 / 昵称 账户标识与个性化展示 必须
电子邮箱 账户验证、通知、找回密码 必须
密码（哈希值） 身份验证（仅存储加密哈希） 必须
API Key 程序化接口访问认证 可选

1.2 自动收集的信息

  • 日志数据 - 访问时间、请求路径、响应状态码等服务器日志
  • 设备信息 - IP 地址、浏览器类型、操作系统（用于安全审计）
  • 使用统计 - API 调用次数、模型使用情况（用于服务优化）

我们不会收集您的聊天记录、对话内容或推理输入的明文数据。

信息如何使用

我们收集的信息将用于以下目的：

  • 提供、维护和保护服务 - 账户管理、身份认证、安全防护
  • 改进和优化服务 - 分析使用模式，提升用户体验和服务质量
  • 发送通知 - 服务变更、安全警报、重要公告
  • 安全保障 - 检测和防范欺诈、滥用行为和安全威胁
  • 法律合规 - 满足法律法规要求

Cookie 与同类技术

为提升用户体验，我们可能使用以下技术：

  • Session Cookie - 用于维持登录状态，会话结束后自动删除
  • 偏好设置 - 记录您的界面偏好（如主题设置），便于下次访问

我们不使用第三方追踪 Cookie 进行广告定向。

信息存储与安全

4.1 存储位置

您的数据存储在我们控制的服务器中。我们采用行业标准的加密技术保护数据安全。

4.2 安全措施

  • 传输加密 - 所有数据传输采用 HTTPS/TLS 加密
  • 存储加密 - 密码使用 bcrypt/argon2 等强哈希算法单向加密存储
  • 访问控制 - 基于角色的权限管理系统，最小权限原则
  • 安全审计 - 定期进行安全评估和渗透测试
  • 入侵检测 - 实时监控异常访问和行为分析

4.3 数据保留

我们仅在实现本政策所述目的所需的期限内保留您的个人信息：

  • 账户信息：在账户存续期间及注销后30天内（用于争议处理）
  • 日志数据：最长保留90天
  • 逾期后将自动匿名化处理或安全删除

信息共享

我们承诺：不会出售、出租或以其他方式向第三方披露您的个人信息，除非以下情形：

  • 获得您的明确同意
  • 法律法规要求 - 根据法院命令、监管要求或其他法律义务
  • 保护合法权益 - 为防止欺诈、保障用户或公众的安全
  • 业务转让 - 如发生合并、收购或资产转让（将提前通知您）

您的权利

根据相关法律法规，您享有以下权利：

  • 知情权 - 了解我们收集了哪些关于您的信息
  • 获取权 - 获取我们持有的您的个人信息副本
  • 更正权 - 更正不准确或不完整的个人信息
  • 删除权 - 要求删除您的个人信息（注销账户）
  • 撤回同意 - 撤回此前给予的任何同意

如需行使上述权利，请通过文末提供的联系方式与我们联系。我们将在合理期限内（通常不超过15个工作日）回应您的请求。

服务类型 提供商 用途

未成年人保护

我们的平台主要面向成年用户。如果您是未满18周岁的未成年人，请在监护人的陪同下阅读本政策，并在获得监护人同意后使用我们的服务。

如发现我们在未事先获得可证实的父母同意的情况下收集了未成年人的个人信息，请联系我们，我们将尽快删除相关数据。

政策变更

我们可能会不时更新本隐私政策。重大变更将通过以下方式通知您：

  • 在本页面发布更新日期和新版本
  • 通过平台内通知或邮件提醒
  • 注册时的邮箱通知（如适用）

建议您定期查阅本页面以了解最新版本。

  • GitHub Issues：提交隐私相关问题
